# Algorithms

1. **FTCS**
Fairness-aware Truss-based Community Search (FTCS) finds a fair k-truss community containing the query vertex q.

2. **AFTCS**
Anchor-based Fairness-aware Truss-based Community Search (AFTCS) discovers an anchored fair k-truss community containing the query vertex q.
